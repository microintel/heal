Scheduled start (24h, this device's clock)
Idle — set a time and tap Arm

Once armed, the tone is scheduled on the Web Audio clock, which starts it with sample-accurate precision (about 20µs at 48kHz) — far tighter than a timer callback could. The wall-clock target is only as good as this device's system clock though, so for a two-device ANC test: sync both devices' clocks first, enter the same HH:MM:SS.mmm on both, set one to 0° and the other to 180° flip, and Arm both a few seconds ahead of that time.
